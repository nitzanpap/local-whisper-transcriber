    Transcription models
    
A model is what turns sound into words. Bigger ones are
      more accurate and slower. They are ordinary files kept in a folder of your own, so anything
      you download here can be used by other tools too — and a model you already have is picked up
      wherever it is.

    Advanced

    

      
      
      
Names, jargon, product names. Telling it
        which words to expect makes it reach for them instead of guessing. A couple of lines
        is plenty; unrelated words make things worse.

    


    

      

        
        

      

      

        
        

      

    

    
Used only when both sources are recorded, because only then is it
      known who said which line.


    

      
      

        
      

    


    

      
      

        
      

    

    
An hour of recording is about 0.7 GB. When a new recording is
      saved, older ones past this many are deleted — the audio only, so their transcripts stay. Files this app
      did not record are never touched.
